# **App Name**: My AI Journal

## Core Features:

- Journal Entry: A large text area for users to write their journal entry.
- Save Entry: A 'Save Entry' button below the text area for users to save each entry.
- Past Entries: A section titled 'Past Entries' which displays a card for each saved entry.
- AI-Powered Sentiment Analysis: An AI-Powered Sentiment Analysis tool badge for each journal entry which analyzes the entry and provides a list of one or two emotions that best describe it, under the heading 'How I felt today'.

## Style Guidelines:

- Primary color: Calm blue (#64B5F6) to promote a sense of peace and reflection.
- Background color: Soft, desaturated blue (#E3F2FD), close to the primary color but lighter and less intense to provide a calming backdrop.
- Accent color: Muted green (#81C784) for a touch of positivity and balance, complementing the primary blue.
- Font: 'Literata', a serif font with a literary feel, suitable for both headings and body text, enhancing readability and creating a comfortable journaling experience.
- Clean and simple layout with a focus on readability and ease of use.
- Simple, minimalist icons for the save button and navigation, providing a clean and intuitive user interface.
- Subtle fade-in animations for new journal entries and sentiment analysis results.
